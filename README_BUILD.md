# HydroGram — Нишевый мод для Telegram на Android

- Пакет модуля: `dev.hydrogram.mod`
- Целевой клиент: `org.telegram.messenger`
- Активных хуков: `11`
- Скругление пузырей: `20dp`
- Скорость анимаций: `70%`

## Быстрая сборка APK через GitHub Actions
1. Загрузите файлы из архива в репозиторий GitHub (включая `.github/workflows/build-apk.yml`).
2. Запустите **Actions** -> **Build HydroGram APK** -> **Run workflow**.
3. Скачайте `app-debug.apk` и подключите его к Telegram через **LSPatch** (без Root) или **LSPosed**.
